# AI 사용법

좋은 결과를 얻기 위해 프롬프트 한 줄만 계속 고치는 단계에서 출발해, AI가 도구를 사용하며 긴 작업을 안정적으로 끝내는 환경을 만드는 단계까지 차근차근 정리한다.

## 한눈에 보는 전체 구조

```text
프롬프트       무엇을 원하는지 명확히 전달한다
    ↓
컨텍스트       판단에 필요한 자료와 상태를 공급한다
    ↓
루프           관찰하고 행동하고 검증하는 반복을 만든다
    ↓
그래프         여러 단계와 분기, 재시도 경로를 연결한다
    ↓
하네스         도구·권한·환경·기록·안전장치를 하나로 묶는다
    ↓
평가           실제로 좋아졌는지 측정하고 다시 개선한다
```

각 단계는 앞 단계를 없애는 기술이 아니다. 좋은 하네스 안에도 좋은 프롬프트가 필요하고, 좋은 그래프도 정확한 컨텍스트와 평가 기준이 없으면 안정적으로 동작하지 않는다.

## 어디부터 읽어야 할까

- ChatGPT에 질문을 잘하고 싶다면 1편부터 읽는다.
- 긴 문서나 사내 자료를 정확히 다루고 싶다면 2편이 중요하다.
- 검색, 코딩, 파일 수정처럼 도구를 쓰는 AI를 만들고 싶다면 3편부터 이어서 읽는다.
- 고정된 업무 절차와 복잡한 분기가 있다면 4편을 본다.
- 반복 가능한 팀 업무나 코딩 에이전트 환경을 만들고 싶다면 5편을 본다.
- 운영 품질을 숫자로 관리하려면 반드시 6편까지 연결한다.

{: .tip }
대부분의 문제는 처음부터 복잡한 멀티 에이전트가 필요하지 않다. 좋은 프롬프트와 정확한 컨텍스트로 시작하고, 실제 실패가 확인될 때 루프와 그래프, 하네스를 한 층씩 추가하는 편이 관리하기 쉽다.
