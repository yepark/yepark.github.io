# MLX

Apple 실리콘 Mac에서 머신러닝을 돌리는 도구, MLX를 **가장 기초부터** 하루에 하나씩 배운다.

머신러닝을 몰라도 괜찮다. Python을 조금 써 본 정도면 따라올 수 있게 쓴다.

## 순서

| 편 | 내용 |
| --- | --- |
| 1 | MLX가 뭐고, 내 Mac에서 처음 돌려 보기 |
| 2 | 배열: MLX에서 숫자를 담는 그릇 |
| 3 | 게으른 계산: MLX는 왜 계산을 미룰까 |
| 4 | 통합 메모리: CPU와 GPU가 같은 책상을 쓴다 |
| 5 | 자동 미분: 기울기를 대신 구해 주는 `mx.grad` |
| 6 | 처음으로 모델 학습시키기: 직선 맞추기 |
| 7 | `mlx.nn`으로 작은 신경망 만들기 |
| 8 | 내 Mac에서 LLM 돌려 보기: `mlx-lm` |

글이 올라오는 대로 왼쪽 메뉴에 추가된다.
